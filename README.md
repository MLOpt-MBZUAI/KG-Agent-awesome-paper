# Awesome KG-Agent Papers

A curated list of papers on knowledge-graph-enhanced agents, LLM reasoning over knowledge graphs, KG-RAG, and agentic knowledge-graph construction.

## Scope and coverage

- **Venues:** ICLR, ICML, and NeurIPS main conference only.
- **Years:** 2025 and 2026, verified through **2026-08-21**.
- **Included:** KG-grounded agent reasoning, KG-RAG, KGQA with LLMs, and agentic KG construction or enrichment.
- **Excluded:** workshops, position papers, submissions, withdrawn papers, and arXiv-only work.
- **NeurIPS 2026:** not yet available on the verification date, so no submission or rebuttal manuscript is listed as accepted work.
